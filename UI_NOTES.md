# Android spike UI

Primary flow: Tambah audio -> paste an authorized HTTPS URL -> real foreground progress -> a file saved to Music/SwarariaAudioLab -> local player -> organizer rename with the extension preserved.

Native Compose/Material 3, system font, dark surfaces with a teal accent; no remote fonts or image service. Copy is Indonesian and task-oriented. Three final destinations: Tambah, Player, Organizer. Empty/loading/denied-notification/validation/failure states are explicit; actual engine output is shown only as diagnostic detail. No fabricated tracks or progress.

No emulator/physical phone is available in the approved build environment. Source/build inspection is not a visual render or a device usability test; those checks remain for the phone handoff. Do not represent a mockup as an actual APK screenshot.
